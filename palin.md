### Palindrome Checker

**Problem Statement:**
Write a program to determine if a given word is a palindrome. A palindrome is a word that reads the exact same forwards and backwards. You must find the length of the string manually. Do not use any external libraries or functions to reverse the string.

**Constraints:**

* The input will be a single word containing only lowercase English letters.
* The maximum length of the word is 100 characters.

**Sample Input 1:**

> radar

**Sample Output 1:**

> Yes

**Sample Input 2:**

> esc

**Sample Output 2:**

> No
