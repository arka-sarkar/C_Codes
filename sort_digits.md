**Scalar Digit Rearrangement**

**Problem Statement:**
Implement a function `sortDigitsDescending` that accepts a non-negative integer and returns a new integer composed of the identical digits rearranged into strictly descending numerical sequence. The implementation must utilize modular arithmetic and nested iterative loops to isolate and append digits.

**Constraints:**

* No arrays, pointers, or string conversions.
* Must operate entirely through pass-by-value integer manipulation.

**Test Cases:**

* **Input:** `273914` | **Expected Output:** `974321`
* **Input:** `5522` | **Expected Output:** `5522`
* **Input:** `1000` | **Expected Output:** `1000` (leading zeros implicitly dropped in integer representation)
