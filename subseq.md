### Is Subsequence

**Problem Statement:**
Given two strings, determine if the first string is a subsequence of the second string. A subsequence is a new sequence generated from the original string by deleting some characters (or none) without changing the relative order of the remaining characters.

**Constraints:**

* The input consists of two words separated by a newline. The first word is the sequence to search for, and the second word is the text to search within.
* The strings will contain only lowercase English letters.
* The maximum length of each string is 100 characters.

**Sample Input 1:**

> abc
> ahbgdc

**Sample Output 1:**

> Yes

**Sample Input 2:**

> axc
> ahbgdc

**Sample Output 2:**

> No
