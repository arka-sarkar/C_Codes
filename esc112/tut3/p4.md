### Dynamic Jagged Array for Committee Hours

**Problem Statement:**
A student club consists of $m$ committees ($1 \le m \le 20$). Each committee $i$ has a different number of members $k_i \ge 1$. Each member logs their volunteer hours as an integer.

Because the number of members varies per committee, store the hours in a dynamically allocated jagged 2D array `int **hours` (an array of $m$ row pointers where each row has its own length $k_i$).

Write and use the following functions:
1. `int **alloc_jagged(int m, const int *sizes)`: Allocates an array of $m$ row pointers. For each committee $i$, allocates a block of `sizes[i] * sizeof(int)`. If any allocation fails, immediately deallocates all previously allocated rows, frees the row pointer array, and returns `NULL`.
2. `void free_jagged(int **arr, int m)`: Properly frees each individual row, and then frees the row-pointer block.
3. `void committee_stats(const int *row, int n, int *sum, double *avg)`: Calculates the total hours and average hours of a committee using pointer traversal, returning both values through output parameters.
4. `void find_top_contributor(int **arr, const int *sizes, int m, int *best_hours, int *best_committee, int *best_member)`: Traverses the jagged array to find the single highest volunteer hours recorded. Returns the hours, committee index, and member index through output parameters (if there is a tie, return the first one encountered).

In `main`:
- Read $m$.
- Read $m$ integers representing the sizes $k_0, k_1, \dots, k_{m-1}$.
- Dynamically allocate the jagged array using `alloc_jagged`.
- Read the hours for each committee member.
- For each committee $i$, print: `Committee <i>: Total = <sum>, Average = <avg>` (average formatted to 2 decimal places).
- Print the top contributor: `Top Contributor: <best_hours> hours (Committee <best_committee>, Member <best_member>)`.
- Free all dynamically allocated memory cleanly without any memory leaks.
