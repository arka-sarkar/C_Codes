### Indirect Row Sorting of Static Matrix via Pointer Array

**Problem Statement:**
Given an n times 3 matrix of integers (`#define COLS 3`, 1 <= n <= 20) stored in `int matrix[20][COLS]`. Instead of copying and swapping whole rows of integers, maintain an array of pointers `int *row_ptrs[20]` initialized such that `row_ptrs[i] = matrix[i]`.

Because all elements of a static 2D array sit in one contiguous memory block, pointer subtraction can be used to recover the original row index: `(row_ptrs[i] - matrix[0]) / COLS`.

Write and use the following functions:
1. `int row_magnitude_sq(const int *r, int c)`: Computes the sum of squares of elements in the row using pointer traversal: $\sum_{j=0}^{c-1} (*(r + j))^2$.
2. `void sort_rows_by_magnitude(int *row_ptrs[], int n, int cols)`: Sorts the array of row pointers in ascending order of their row magnitude (sum of squares). When two rows have the same magnitude, preserve their relative order (stable sort). When swapping, swap **only the pointers** in `row_ptrs`, without touching the underlying `matrix`.

In `main`:
- Read $n$, followed by $n$ lines of 3 integers each into `matrix`.
- Initialize `row_ptrs[i] = matrix[i]`.
- Sort the row pointers using `sort_rows_by_magnitude`.
- For each row in sorted order, print:
  `[Original Row <orig_idx>] <val0> <val1> <val2> (Magnitude: <mag>)`
  where `<orig_idx>` is calculated using pointer subtraction `(row_ptrs[i] - matrix[0]) / COLS` (printed with `%td`).
- Print `"Original Matrix:"` followed by the matrix elements row by row, confirming that the underlying matrix remains in its initial untouched order.
