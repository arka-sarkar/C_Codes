### Word Case Inversion and Statistics using Array of Pointers

**Problem Statement:**
Write a C program that reads $n$ words ($1 \le n \le 10$, each word containing at most 29 characters). Store the words in a 2D array `char store[10][30]` and maintain an array of pointers `char *words[10]`, where each pointer `words[i]` points to the corresponding row `store[i]`. All word reading and manipulation must be performed through the pointer array `words`.

Implement and use the following functions:
1. `void count_cases(const char *s, int *upper, int *lower)`: Traverses the string using pointer `s` (`while (*s != '\0')`) and returns the counts of uppercase and lowercase alphabetic letters through the output pointer parameters.
2. `void toggle_case(char *s)`: Inverts the case of each alphabetic character in the string in place (lowercase to uppercase, uppercase to lowercase) by walking through the string with pointer `s`. Non-alphabetic characters should remain unchanged.

In `main`:
- Read the integer n.
- Read n words into `words[i]`.
- For each word, call `count_cases` to get its original uppercase and lowercase counts, then call `toggle_case` to invert its case in place.
- Print each modified word along with its original uppercase and lowercase counts: `<modified_word> <upper> <lower>`.
- Finally, find and print the word that has the maximum total number of alphabetic letters (`upper + lower`). If multiple words have the same maximum count, print the first one encountered.
