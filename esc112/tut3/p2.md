### Row-wise Analysis and Conditional Scaling of a Static 2D Array

**Problem Statement:**
In a laboratory experiment, a sensor records readings across $n$ time steps ($1 \le n \le 15$) over 4 channels (`#define CHANNELS 4`). Store the readings in a static 2D array `int data[15][CHANNELS]`.

Because each row in a static 2D array is a contiguous 1D array, any 1D array function can operate directly on a single row `data[i]`. Write and use the following functions:

1. `void row_min_max(const int *row, int n, int *min_val, int *max_val)`: Traverses a single row using a pointer (`const int *p`) and returns the row's minimum and maximum values through the output pointer parameters.
2. `void scale_row(int *row, int n, int factor)`: Multiplies every element in the row by `factor` in place using pointer traversal.
3. `int column_max(int data[][CHANNELS], int n, int col)`: Finds and returns the maximum value in column `col` across all $n$ rows.

In `main`:
- Read $n$, followed by $n$ times $4$ integers.
- For each row i:
  - Call `row_min_max(data[i], CHANNELS, &min_val, &max_val)`.
  - Print the row statistics: `Row <i>: min=<min_val>, max=<max_val>`.
  - If `max_val - min_val > 20`, amplify the row by calling `scale_row(data[i], CHANNELS, 2)`.
- Print the entire updated matrix row by row (each row on a separate line, elements separated by spaces).
- On the final line, print the maximum value for each of the 4 columns separated by spaces.
