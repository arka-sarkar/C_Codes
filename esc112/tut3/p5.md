### Dynamic Matrix Allocation via Triple Pointer and Matrix Transpose-Multiplication

**Problem Statement:**
When allocating memory inside a function for a caller's pointer variable, passing `T*` only passes a copy of the pointer. To modify the caller's pointer variable itself, the function must receive the pointer's address (`T**` for a simple pointer, or `T***` for a dynamic 2D array pointer `int **`).

Write a C program that allocates an $m \times n$ dynamic 2D matrix directly into the caller's pointer via an `int ***` parameter, computes its transpose, and calculates its Gram matrix product ($G = A \times A^T$).

Write and use the following functions:
1. `int alloc_matrix(int ***pA, int rows, int cols)`: Allocates an array of `rows` pointers into `*pA`. For each row, allocates `cols` integers. If any allocation fails, immediately frees any previously allocated memory in this function, sets `*pA = NULL`, and returns 0. On success, returns 1.
2. `void free_matrix(int **M, int rows)`: Properly frees each row block first, then frees the row-pointer block.
3. `int **transpose(int **A, int rows, int cols)`: Allocates and returns a new $cols \times rows$ dynamic matrix $T$ such that $T[j][i] = A[i][j]$.
4. `int **multiply(int **A, int r1, int c1, int **B, int r2, int c2)`: Checks that $c1 == r2$. Allocates and returns a new $r1 \times c2$ dynamic matrix $C$ containing the product $A \times B$, where:
   $$C[i][j] = \sum_{k=0}^{c1 - 1} A[i][k] \times B[k][j]$$
5. `void print_matrix(int **M, int rows, int cols)`: Prints the matrix elements row by row, with elements separated by spaces.

In `main`:
- Read dimensions $m$ and $n$ ($1 \le m, n \le 10$).
- Declare `int **A = NULL;` and allocate it by calling `alloc_matrix(&A, m, n)`.
- Read the $m \times n$ integers into $A$.
- Compute $T = transpose(A, m, n)$ (dimensions $n \times m$).
- Compute $G = multiply(A, m, n, T, n, m)$ (dimensions $m \times m$).
- Print `"Transpose:"` followed by the matrix $T$.
- Print `"Product (A * A^T):"` followed by the matrix $G$.
- Cleanly deallocate all dynamically allocated matrices ($A$, $T$, and $G$) using `free_matrix`.
