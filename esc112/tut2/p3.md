### Substring Search and Indexing via Pointers

**Problem Statement:**
Write a C program that reads two strings: a `main_str` and a `sub_str`. Use the `<string.h>` function `strstr` to find the first occurrence of `sub_str` inside `main_str`. If the substring is found, calculate its starting index by subtracting the base pointer (`main_str`) from the pointer returned by `strstr`. Print the calculated index. If `strstr` returns `NULL` (meaning the substring is not found), print `"Not found"`.

**Test Cases:**

* **Test Case 1:**
* *Input:* `programming gram`
* *Output:* `Index: 3`


* **Test Case 2:**
* *Input:* `hello world`
* *Output:* `Not found`
