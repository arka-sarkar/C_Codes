### String Analysis using Pointer Arithmetic

**Problem Statement:**
Write a C program that reads a single string from the user. Using *only* a pointer to traverse the string (do not use integer indices like `s[i]`), count the number of uppercase English letters in the string. When the pointer reaches the null terminator (`'\0'`), calculate the total length of the string by subtracting the original string pointer from your current pointer. Print both the uppercase count and the calculated length. Do not use `strlen()`.

**Test Cases:**

* **Test Case 1:**
* *Input:* `HelloWorld`
* *Output:* `Uppercase: 2, Length: 10`


* **Test Case 2:**
* *Input:* `pointers`
* *Output:* `Uppercase: 0, Length: 8`
