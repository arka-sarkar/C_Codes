### Lexicographical Search and Concatenation

**Problem Statement:**
Write a C program that declares three separate character arrays of size 50 and an array of 3 pointers pointing to these arrays. Read three words from the user into these arrays using the pointers. Using `strcmp`, find the lexicographically smallest word among the three. Then, use `strcpy` to copy this smallest word into a new `result` array, and use `strcat` to append the literal string `"_min"` to it. Print the final `result` array.

**Test Cases:**

* **Test Case 1:**
* *Input:* `banana apple cherry`
* *Output:* `Result: apple_min`


* **Test Case 2:**
* *Input:* `zebra yak xylophone`
* *Output:* `Result: xylophone_min`
