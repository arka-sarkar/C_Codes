### Sorting Emails by Domain Name

**Problem Statement:**
Write a C program that reads four email addresses into separate character arrays. Your goal is to sort and print these full email addresses based strictly on their **domain names** (the part of the string after the `@` symbol) in lexicographical order.

To do this efficiently without duplicating any string data:

1. Maintain two arrays of pointers: one pointing to the start of the full email (`full_ptrs`), and one pointing to the start of the domain name (`domain_ptrs`).


2. Use `strchr` to find the `@` symbol in each email.


3. Use pointer arithmetic to set the `domain_ptrs` to point exactly one character *after* the `@` symbol.


4. Perform a bubble sort using `strcmp` on the `domain_ptrs`, but whenever you swap two domain pointers, you must **also swap the corresponding pointers in `full_ptrs**` so they remain synced.


5. Finally, print the full emails in their new sorted order.

**Test Cases:**

* **Test Case 1:**
* *Input:* `alice@zmail.com bob@apple.com charlie@yahoo.com dave@bing.com`
* *Output:*
`bob@apple.com`
`dave@bing.com`
`charlie@yahoo.com`
`alice@zmail.com`
