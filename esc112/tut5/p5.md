### Recursive Grid Maze Solver with Backtracking and Path Unwinding

**Problem Statement:**
Backtracking is a recursive problem-solving strategy that attempts to build a solution incrementally, abandoning ("backtracking" during stack unwinding) as soon as it determines that a candidate cannot lead to a valid solution.

Given an $R \times C$ maze represented as a 2D integer grid:
- `0` represents an open passable cell.
- `1` represents an impassable obstacle/wall.

Write a recursive function to find a simple path from the top-left start $(0, 0)$ to the bottom-right destination $(R-1, C-1)$.

**Movement & Backtracking Rules:**
From cell $(r, c)$, the solver explores adjacent valid cells in the following order:
1. Down $(r+1, c)$
2. Right $(r, c+1)$
3. Up $(r-1, c)$
4. Left $(r, c-1)$

If all 4 directions lead to dead ends, the solver **backtracks**: it unmarks cell $(r, c)$ from the current path before returning `0`, allowing other alternative paths to be explored.

**Requirements:**
1. `int solve(int maze[20][20], int r, int c, int R, int C, int path[20][20])`:
   - Returns `1` if a path reaches $(R-1, C-1)$, or `0` otherwise.
   - Marks cells along the active path in `path[r][c]`.
2. In `main`:
   - If a path is found, print `Path found:` followed by the grid where:
     - `'*'` represents a cell along the solution path.
     - `'#'` represents a wall.
     - `'.'` represents an unused open cell.
   - If no path exists, print `No path found`.

**Input Format:**
- Two integers $R$ and $C$ ($2 \le R, C \le 20$).
- $R$ lines of $C$ integers each (`0` or `1`). Assume $(0, 0)$ and $(R-1, C-1)$ start as `0`.

**Test Cases:**

* **Test Case 1:**
* *Input:*
```
4 4
0 0 1 0
1 0 1 0
0 0 0 1
0 1 0 0
```
* *Output:*
```
Path found:
* * # . 
# * # .

```

```

```
