### Recursive Subsequence Matching and In-Place Duplicate Pruning

**Problem Statement:**
Recursive string processing allows traversal, search, and transformation of strings without using any iterative loops (`for`, `while`, `do-while`). Implement three recursive string manipulation functions that operate purely through recursion.

**Requirements:**
1. `int count_char(const char *s, char c)`: Recursively counts how many times character `c` appears in string `s`.
2. `int is_subsequence(const char *s1, const char *s2)`: Recursively determines if string $s_1$ is a subsequence of string $s_2$ (i.e., whether all characters of $s_1$ appear in $s_2$ in the same relative order). Returns `1` if true, `0` otherwise.
3. `void remove_consecutive_duplicates(char *s)`: Recursively eliminates adjacent duplicate characters in place (e.g. `"baaoookk"` becomes `"baok"`).
4. **Constraint**: Loops (`for`, `while`, `do-while`) are **strictly forbidden** inside the functions. All traversal must be achieved via recursion.

**Input Format:**
Three whitespace-separated tokens on a single line:
`s1 s2 target_char`
where $s_1$ and $s_2$ are strings of at most 99 lowercase English letters, and `target_char` is a single character.

**Output Format:**
- `Count of '<target_char>' in s1: <count>`
- `Is s1 subsequence of s2: YES/NO`
- `s2 after deduplication: <modified_s2>`

**Test Cases:**

* **Test Case 1:**
* *Input:* `ace abcde c`
* *Output:*
```
Count of 'c' in s1: 1
Is s1 subsequence of s2: YES
s2 after deduplication: abcde
```

* **Test Case 2:**
* *Input:* `book baaoookk o`
* *Output:*
```
Count of 'o' in s1: 2
Is s1 subsequence of s2: YES
s2 after deduplication: baok
```
