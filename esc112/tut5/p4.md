### Recursive Bitonic Peak Finding and Divide-and-Conquer Search

**Problem Statement:**
A **bitonic sequence** is an array of distinct integers that first monotonically increases to a maximum element (the peak), and then monotonically decreases. For example: `[1, 3, 8, 12, 19, 14, 7, 2]` has its peak at element `19` (index 4).

Because the array is not uniformly sorted, a standard binary search fails. However, using **recursive divide-and-conquer**:
1. The peak can be located in $O(\log n)$ time by comparing $a[\text{mid}]$ with $a[\text{mid} + 1]$.
2. Once the peak is known, the array is partitioned into two independently sorted halves: an ascending subarray $a[0 \dots \text{peak}]$ and a descending subarray $a[\text{peak}+1 \dots n-1]$.
3. A target value can then be found in $O(\log n)$ by recursively searching the ascending half, and if absent, searching the descending half.

**Requirements:**
1. `int find_peak(const int a[], int lo, int hi)`: Recursively finds and returns the index of the peak element in $O(\log n)$ time.
2. `int bin_search_asc(const int a[], int lo, int hi, int x)`: Recursively searches for $x$ in an ascending sorted subarray in $O(\log n)$ time. Returns index, or `-1` if absent.
3. `int bin_search_desc(const int a[], int lo, int hi, int x)`: Recursively searches for $x$ in a descending sorted subarray in $O(\log n)$ time. Returns index, or `-1` if absent.
4. In `main`:
   - Print `Peak element: <val> at index <idx>`.
   - For each query target $x$: print `Target <x>: found at index <idx>` or `Target <x>: not found`.

**Input Format:**
- An integer $n$ ($3 \le n \le 100$).
- $n$ integers forming a bitonic array.
- An integer $q$ ($1 \le q \le 50$) followed by $q$ target values.
