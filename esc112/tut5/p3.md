### Recursive Hourglass Pattern via Stack Unwinding

**Problem Statement:**
A single recursive function can execute operations **before** the recursive call (during descent) and **after** the recursive call (during stack unwinding), generating perfectly symmetric patterns without iterative loops.

Use this principle to print an **Hourglass Pattern** of stars of size $n$, containing $2n - 1$ rows in total.

**Hourglass Specification:**
For a positive integer $n$:
- Top row ($r = 1$): $0$ spaces followed by $2n - 1$ stars.
- Row $r$ ($1 \le r \le n$): $r - 1$ spaces followed by $2(n - r) + 1$ stars.
- Middle row ($r = n$): $n - 1$ spaces followed by $1$ star (printed only once).
- Bottom half: As the recursion unwinds, rows $r = n - 1$ down to $1$ are printed again in reverse order.
- **Constraint**: No loops (`for`, `while`, `do-while`) are allowed anywhere in the program. All repetition must be done using recursion.

**Requirements:**
1. `void print_chars(char c, int k)`: Recursively prints character `c` exactly `k` times.
2. `void print_row(int row, int n)`: Prints row `row` of the hourglass using `print_chars`.
3. `void print_hourglass(int row, int n)`: Recursively generates the upper half during descent and the lower half during stack unwinding.

**Input Format:**
A single integer $n$ ($1 \le n \le 20$).
