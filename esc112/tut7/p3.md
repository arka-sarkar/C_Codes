### 32-Bit Bitmask Set and Access Controller

**Problem Statement:**
In systems programming and database engines, sets of small integers from $\{0, 1, \dots, 31\}$ (such as user permission flags, active thread IDs, or available hardware channels) are represented compactly using a single 32-bit unsigned integer `mask`. An element $i$ belongs to the set if and only if bit $i$ is `1` (`(mask & (1U << i)) != 0`).

Implement an interactive bitmask set controller that maintains a 32-bit integer `mask` under a series of operations.

**Supported Operations:**
1. `ADD pos`: Adds element $pos$ ($0 \le pos \le 31$) to the set.
   - Bitwise formula: `mask |= (1U << pos)`
   - Prints: `Added <pos>: mask=0x<8-HEX>`
2. `REMOVE pos`: Removes element $pos$ ($0 \le pos \le 31$) from the set.
   - Bitwise formula: `mask &= ~(1U << pos)`
   - Prints: `Removed <pos>: mask=0x<8-HEX>`
3. `CONTAINS pos`: Checks if element $pos$ is present.
   - Prints: `Contains <pos>: YES` or `Contains <pos>: NO`
4. `COUNT`: Counts how many elements are currently in the set (Hamming weight / popcount).
   - Must be computed using **Brian Kernighan's bit-clearing loop** (`v &= (v - 1)`).
   - Prints: `Size: <count>`
5. `UNION other_mask`: Performs set union between the current mask and an unsigned 32-bit integer `other_mask` (`mask |= other_mask`).
   - Prints: `Union: mask=0x<8-HEX> size=<new_size>`
6. `INTERSECT other_mask`: Performs set intersection between the current mask and `other_mask` (`mask &= other_mask`).
   - Prints: `Intersect: mask=0x<8-HEX> size=<new_size>`
7. `PRINT`: Lists all elements currently in the set in ascending order separated by spaces, or prints `EMPTY` if the mask is 0.
   - Prints: `Elements: <e0> <e1> ...` or `Elements: EMPTY`

**Input Format:**
- The first line contains the initial mask $M$ ($0 \le M \le 4294967295$) and the number of queries $Q$ ($1 \le Q \le 100$).
- The following $Q$ lines each contain one operation as described above.

**Output Format:**
Print the corresponding message for each operation, formatting hexadecimal masks as `0x%08X`.

**Test Cases:**

* **Test Case 1:**
* *Input:*
```
5 8
ADD 3
CONTAINS 2
CONTAINS 1
COUNT
REMOVE 0
UNION 18
PRINT
INTERSECT 6
```
* *Explanation:*
  - Initial mask: $5 = 00000101_2$ (contains $\{0, 2\}$).
  - `ADD 3`: sets bit 3 $\to 13 = 00001101_2$ (`0x0000000D`).
  - `CONTAINS 2`: bit 2 is 1 $\to$ `YES`.
  - `CONTAINS 1`: bit 1 is 0 $\to$ `NO`.
  - `COUNT`: bits 0, 2, 3 are set $\to$ size 3.
  - `REMOVE 0`: clears bit 0 $\to 12 = 00001100_2$ (`0x0000000C`).
  - `UNION 18`: $18 = 00010010_2$ (bits 1, 4). Union with $\{2, 3\}$ produces $\{1, 2, 3, 4\} = 30$ (`0x0000001E`), size 4.
  - `PRINT`: prints `Elements: 1 2 3 4`.
  - `INTERSECT 6`: $6 = 00000110_2$ (bits 1, 2). Intersection with $\{1, 2, 3, 4\}$ produces $\{1, 2\} = 6$ (`0x00000006`), size 2.
* *Output:*
```
Added 3: mask=0x0000000D
Contains 2: YES
Contains 1: NO
Size: 3
Removed 0: mask=0x0000000C
Union: mask=0x0000001E size=4
Elements: 1 2 3 4
Intersect: mask=0x00000006 size=2
```

* **Test Case 2:**
* *Input:*
```
0 4
PRINT
ADD 31
COUNT
PRINT
```
* *Output:*
```
Elements: EMPTY
Added 31: mask=0x80000000
Size: 1
Elements: 31
```
