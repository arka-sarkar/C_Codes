### Circular Bitwise Palindromes and Canonical Rotations

**Problem Statement:**
A 16-bit unsigned integer $x \in [0, 65535]$ is defined to be a **bitwise palindrome** if its binary representation reads identically forwards and backwards across all 16 bits (i.e. bit $k$ equals bit $15 - k$ for every $0 \le k < 16$).

A number is called **circularly palindromic** if there exists some circular left rotation $k \in [0, 15]$ such that the resulting 16-bit integer is a bitwise palindrome.

Given an unsigned 16-bit integer $x$, determine:
1. Whether $x$ itself is a bitwise palindrome (`YES` or `NO`).
2. Whether $x$ is circularly palindromic. If yes, print the smallest left rotation count $k$ ($0 \le k < 16$) that transforms $x$ into a palindrome, along with the decimal value of that palindrome. If no rotation produces a palindrome, report `NO`.
3. The **canonical rotation**: the minimum decimal value achievable among all 16 circular left rotations ($k = 0, 1, \dots, 15$) and the rotation count $k$ that achieves it (smallest $k$ on ties).

**Constraints:**
- All bit operations (reversal and circular shifts) must be implemented using bitwise operators (`<<`, `>>`, `|`, `&`, `^`).
- Arrays and strings are **strictly forbidden**.

**Input Format:**
A single unsigned integer $x$ ($0 \le x \le 65535$).

**Output Format:**
```
Palindrome: YES/NO
Circular Palindrome: YES (rotations=<k> value=<val>) OR Circular Palindrome: NO
Canonical: minimum=<min_val> rotations=<best_k>
```

**Test Cases:**

* **Test Case 1:**
* *Input:* `384`
* *Explanation:*
  $384 = 0000\,0001\,1000\,0000_2$.
  - Bits 7 and 8 are `1`, and all other bits are `0`. Since bit $k = \text{bit}(15-k)$ for all $k$, 384 is already a palindrome.
  - Smallest rotation to form a palindrome is $k = 0$ with value $384$.
  - Rotating left by 9 moves bits 7 and 8 to positions 0 and 1, producing $0000\,0000\,0000\,0011_2 = 3$, which is the minimal value possible.
* *Output:*
```
Palindrome: YES
Circular Palindrome: YES (rotations=0 value=384)
Canonical: minimum=3 rotations=9
```

* **Test Case 2:**
* *Input:* `3`
* *Explanation:*
  $3 = 0000\,0000\,0000\,0011_2$ (bits 0 and 1 are `1`).
  - Bit 0 is `1` but bit 15 is `0`, so 3 is not a palindrome.
  - Rotating left by 7 moves bits 0 and 1 to bits 7 and 8, giving $384$ which is a palindrome.
  - The canonical minimum is 3 itself at $k = 0$.
* *Output:*
```
Palindrome: NO
Circular Palindrome: YES (rotations=7 value=384)
Canonical: minimum=3 rotations=0
```

* **Test Case 3:**
* *Input:* `43690`
* *Explanation:*
  $43690 = 1010\,1010\,1010\,1010_2$.
  - No circular rotation ever yields a bit-palindrome.
  - Rotating left by 1 produces $0101\,0101\,0101\,0101_2 = 21845$, which is the minimum value across all rotations.
* *Output:*
```
Palindrome: NO
Circular Palindrome: NO
Canonical: minimum=21845 rotations=1
```
