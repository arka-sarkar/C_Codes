### Bitwise Run-Length and Parity Analysis

**Problem Statement:**
Bitwise operations allow fine-grained inspection and manipulation of individual bits in fixed-width integers without relying on arrays or string buffers.

Given an unsigned 16-bit integer $x \in [0, 65535]$, inspect its 16 bits indexed from $0$ (least significant bit) to $15$ (most significant bit). Compute the following properties using purely bitwise operations and integer arithmetic:

1. **Total Set Bits and Parity:** Count the total number of bits set to `1`. Determine whether this count is `ODD` or `EVEN`.
2. **Longest Run of Consecutive 1-Bits:** Determine the maximum length of consecutive `1`s and the 0-indexed starting position (lowest-numbered position) of that run. If several runs have the same maximum length, pick the one with the smallest starting position. If $x = 0$, the length is `0` and start is `-1`.
3. **Longest Run of Consecutive 0-Bits:** Determine the maximum length of consecutive `0`s and the 0-indexed starting position of that run. Ties are broken by choosing the smallest starting position. If $x = 65535$, the length is `0` and start is `-1`.
4. **Bit Transitions:** Count the number of times adjacent bits differ (i.e. transitions $0 \to 1$ or $1 \to 0$ between bit $k$ and bit $k+1$ for $0 \le k < 15$).

**Constraints:**
- Must use bitwise operators (`>>`, `<<`, `&`, `|`, `^`, `~`).
- Arrays, strings, and string conversions are **strictly forbidden**.

**Input Format:**
A single unsigned integer $x$ ($0 \le x \le 65535$).

**Output Format:**
Print four lines:
```
1-bits: count=<C> parity=<ODD/EVEN>
Longest 1-run: length=<L1> start=<S1>
Longest 0-run: length=<L0> start=<S0>
Transitions: <T>
```

**Test Cases:**

* **Test Case 1:**
* *Input:* `119`
* *Explanation:*
  $119 = 0000\,0000\,0111\,0111_2$.
  - 1s occur at positions $0..2$ and $4..6$ (total 6 set bits $\to$ `EVEN`).
  - Longest 1-run has length 3, starting at position 0 (ties broken by earliest start).
  - 0-runs occur at position 3 (len 1) and positions $7..15$ (len 9). Longest 0-run has length 9 starting at position 7.
  - Transitions occur between positions 2–3, 3–4, and 6–7 (total 3 transitions).
* *Output:*
```
1-bits: count=6 parity=EVEN
Longest 1-run: length=3 start=0
Longest 0-run: length=9 start=7
Transitions: 3
```

* **Test Case 2:**
* *Input:* `4660`
* *Explanation:*
  $4660 = 0001\,0010\,0011\,0100_2$.
  - 1s are at positions 2, 4, 5, 9, 12 (5 set bits $\to$ `ODD`).
  - Longest 1-run is at positions $4..5$ (length 2, start 4).
  - Longest 0-run is length 3, appearing at positions $6..8$ (start 6) and $13..15$ (start 13); earliest is start 6.
  - Transitions: 8.
* *Output:*
```
1-bits: count=5 parity=ODD
Longest 1-run: length=2 start=4
Longest 0-run: length=3 start=6
Transitions: 8
```

* **Test Case 3:**
* *Input:* `0`
* *Output:*
```
1-bits: count=0 parity=EVEN
Longest 1-run: length=0 start=-1
Longest 0-run: length=16 start=0
Transitions: 0
```
