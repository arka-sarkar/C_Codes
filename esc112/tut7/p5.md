### Student Gradebook CSV Processor with Weighted Scoring and Class Statistics

**Problem Statement:**
Academic course administrators manage performance records across several examinations stored in spreadsheet CSV format. Calculating composite course scores, assigning letter grades based on defined cutoffs, ranking students, and generating summary statistics are essential file I/O tasks in C.

Write a command-line program that reads a student assessment CSV file, calculates weighted totals, ranks students, writes a sorted summary CSV file, and reports overall class statistics to `stdout`.

The program must be invoked from the command line as:
```bash
./s5 <input.csv> <output.csv> <w_quiz> <w_mid> <w_end>
```
where `w_quiz`, `w_mid`, and `w_end` are floating-point numbers representing the percentage weights of the three evaluations (which must sum to 100 within a tolerance of $\pm 0.1$).

**Validation & Error Handling:**
1. If `argc != 6`, print to `stderr`:
   `Usage: <argv[0]> <input.csv> <output.csv> <w_quiz> <w_mid> <w_end>\n`
   and exit with status code 1.
2. If the sum of the three weights is outside $[99.9, 100.1]$, print to `stderr`:
   `Error: Weights must sum to 100\n`
   and exit with status code 1.
3. If the input file cannot be opened, print to `stderr`:
   `Cannot open input file\n`
   and exit with status code 1.
4. If the output file cannot be created, print to `stderr`:
   `Cannot create output file\n`
   and exit with status code 1.

**Input CSV File Format:**
The input CSV contains a header row followed by up to 200 records:
```csv
RollNo,Name,Quiz,Midsem,Endsem
```
- `RollNo`: Integer roll number.
- `Name`: String of up to 49 characters (no commas).
- `Quiz`, `Midsem`, `Endsem`: Floating-point examination marks.

**Grading and Ranking Criteria:**
1. Weighted total score:
   $$\text{Total} = \frac{w_q \times \text{Quiz} + w_m \times \text{Midsem} + w_e \times \text{Endsem}}{100}$$
2. Letter grade cutoffs:
   - $\text{Total} \ge 85.0 \implies \text{'A'}$
   - $70.0 \le \text{Total} < 85.0 \implies \text{'B'}$
   - $55.0 \le \text{Total} < 70.0 \implies \text{'C'}$
   - $40.0 \le \text{Total} < 55.0 \implies \text{'D'}$
   - $\text{Total} < 40.0 \implies \text{'F'}$
3. Ranking order:
   - **Primary:** `TotalScore` in **descending** order.
   - **Secondary (ties):** `RollNo` in **ascending** order.

**Output Specifications:**
1. **Output CSV File (`<output.csv>`)**:
   Contains a header row and each student's rank, roll number, name, total score (`%.2f`), and grade:
   ```csv
   Rank,RollNo,Name,TotalScore,Grade
   ```
2. **Standard Output (`stdout`)**:
   ```
   Students processed: <n>
   Class average: <avg_score>
   Highest score: <max_score> (<student_name>)
   Lowest score: <min_score> (<student_name>)
   Grade distribution: A=<cA> B=<cB> C=<cC> D=<cD> F=<cF>
   ```
   (All average, highest, and lowest scores formatted with 2 decimal places `%.2f`).
