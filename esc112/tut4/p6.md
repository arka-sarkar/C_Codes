### Polynomial Arithmetic (Addition & Multiplication) via Sorted Linked Lists

**Problem Statement:**
A univariate polynomial can be represented as a singly linked list of terms sorted in **strictly descending order of exponents**:
$$P(x) = c_k x^{e_k} + c_{k-1} x^{e_{k-1}} + \dots + c_0 x^{e_0} \quad (e_k > e_{k-1} > \dots > e_0)$$

Each node in the list stores:
`typedef struct term { int coeff; int exp; struct term *next; } Term;`

**Canonical Representation Rules:**
- Terms must always remain sorted in descending order of `exp`.
- If an inserted term has the same exponent as an existing term, their coefficients are added together.
- If the coefficient of a term becomes `0` (e.g. through cancellation), that term must be pruned and freed.
- If all terms in a polynomial are zero/cancelled, the polynomial is empty (`NULL`), which prints as `0`.

Implement and use the following functions:
1. `Term *insert_term(Term *head, int coeff, int exp)`: Inserts a term $(coeff, exp)$ into the polynomial while maintaining descending exponent order, combining like terms, and unlinking/freeing terms that cancel to 0. Returns the updated polynomial head.
2. `Term *add_polynomials(const Term *p1, const Term *p2)`: Adds two polynomials and returns a new sorted polynomial representing the sum.
3. `Term *multiply_polynomials(const Term *p1, const Term *p2)`: Multiplies two polynomials: for each term $(c_1, e_1)$ in $p1$ and $(c_2, e_2)$ in $p2$, inserts the product term $(c_1 \cdot c_2, e_1 + e_2)$ into the result polynomial. Returns the resulting sorted product polynomial.
4. `void print_poly(const Term *p)`: Prints terms in the format `<coeff>x^<exp> + ...` (or prints `0` if empty).
5. `void free_poly(Term *head)`: Frees all allocated nodes in the polynomial.

**Input Format:**
- An integer $n_1$ followed by $n_1$ pairs of integers `coeff exp` for the first polynomial.
- An integer $n_2$ followed by $n_2$ pairs of integers `coeff exp` for the second polynomial.

**Output Format:**
- `P1: <polynomial_1>`
- `P2: <polynomial_2>`
- `Sum: <sum_polynomial>`
- `Product: <product_polynomial>`

**Test Cases:**

* **Test Case 1:**
* *Input:*
```
2
3 2
1 0
2
2 1
-1 0
```
* *Output:*
```
P1: 3x^2 + 1x^0
P2: 2x^1 + -1x^0
Sum: 3x^2 + 2x^1
Product: 6x^3 + -3x^2 + 2x^1 + -1x^0
```

* **Test Case 2 (Full Cancellation):**
* *Input:*
```
2
2 2
3 1
2
-2 2
-3 1
```
* *Output:*
```
P1: 2x^2 + 3x^1
P2: -2x^2 + -3x^1
Sum: 0
Product: -4x^4 + -12x^3 + -9x^2
```
