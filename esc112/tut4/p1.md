### Singly Linked List In-Place Reversal & Palindrome Checker

**Problem Statement:**
Write a C program that reads an integer $n$ ($1 \le n \le 50$) followed by $n$ integers, and constructs a singly linked list.

A core operation on linked lists is reversing the list in place without allocating new nodes or copying data into arrays. You must implement in-place reversal using the three-pointer technique (`prev`, `cur`, `next`) introduced in the tutorial.

Implement and use the following functions:
1. `Node *push_back(Node *head, int val)`: Allocates a new node and inserts it at the end of the list.
2. `Node *reverse_list(Node *head)`: Reverses the list in place by rewiring `next` pointers using three pointers (`prev`, `cur`, `next`), and returns the new head. No new nodes may be allocated.
3. `Node *copy_list(const Node *head)`: Creates and returns a duplicate copy of the list.
4. `int is_palindrome(const Node *head)`: Checks if the list elements form a palindrome. Returns `1` if it is a palindrome, or `0` otherwise.
5. `void print_list(const Node *head)`: Prints the list in the format: `val1 -> val2 -> ... -> NULL`.
6. `void free_list(Node *head)`: Frees every node in the list.

In `main`:
- Read integer $n$.
- Read $n$ integers and build the list.
- Print the original list: `Original: val1 -> val2 -> ... -> NULL`.
- Check if the original list is a palindrome: print `Palindrome: YES` or `Palindrome: NO`.
- Reverse the original list in place using `reverse_list`.
- Print the reversed list: `Reversed: val1 -> val2 -> ... -> NULL`.
- Free all allocated memory before termination.

**Test Cases:**

* **Test Case 1:**
* *Input:*
```
5
1 2 3 2 1
```
* *Output:*
```
Original: 1 -> 2 -> 3 -> 2 -> 1 -> NULL
Palindrome: YES
Reversed: 1 -> 2 -> 3 -> 2 -> 1 -> NULL
```

* **Test Case 2:**
* *Input:*
```
4
10 20 30 40
```
* *Output:*
```
Original: 10 -> 20 -> 30 -> 40 -> NULL
Palindrome: NO
Reversed: 40 -> 30 -> 20 -> 10 -> NULL
```
