### Browser History Navigation via Doubly Linked List

**Problem Statement:**
Web browsers implement tab navigation using a doubly linked list. The browser maintains pointers to the first page (`head`), the most recent page in history (`tail`), and the page currently being viewed (`cur`).

Whenever a user navigates backwards and then visits a brand-new page, **all pages ahead of the current page in history must be truncated and freed** before appending the new page to `cur`.

Each page node contains:
`typedef struct page { char url[50]; struct page *prev, *next; } Page;`

Implement and use the following functions:
1. `int visit(const char *url)`:
   - If history is empty, creates the node as `head`, `tail`, and `cur`.
   - If `cur` has forward history (`cur->next != NULL`), deallocates and frees all nodes from `cur->next` to `tail`, and sets `cur->next = NULL`.
   - Attaches the new node after `cur`, updates its `prev` pointer to `cur`, sets `tail` to the new node, and sets `cur` to the new node.
2. `void back(int steps)`:
   - Traverses backward along `prev` pointers by at most `steps` steps (stopping if `cur->prev == NULL`).
   - Prints `current: <url>` (or `history is empty` if no pages exist).
3. `void forward(int steps)`:
   - Traverses forward along `next` pointers by at most `steps` steps (stopping if `cur->next == NULL`).
   - Prints `current: <url>` (or `history is empty` if no pages exist).
4. `void show(void)`:
   - Prints history from `head` to `tail` separated by `<->`, enclosing the active `cur` page in square brackets `[url]`.
5. `void show_rev(void)`:
   - Prints history in reverse from `tail` to `head` following `prev` pointers, verifying that bidirectional linkage is preserved.
6. `void free_all(void)`:
   - Frees all nodes in the list.

**Command Set:**
- `visit <url>`
- `back <steps>`
- `forward <steps>`
- `current`: Prints `current: <url>`.
- `show`
- `rev`
- `end`: Frees all memory and exits.

**Test Cases:**

* **Test Case 1:**
* *Input:*
```
visit google.com
visit youtube.com
visit github.com
show
back 1
back 1
forward 1
visit reddit.com
show
rev
end
```
* *Output:*
```
google.com <-> youtube.com <-> [github.com]
current: youtube.com
current: google.com
current: youtube.com
google.com <-> youtube.com <-> [reddit.com]
[reddit.com] <-> youtube.com <-> google.com
```

* **Test Case 2:**
* *Input:*
```
visit home.html
back 5
forward 5
current
end
```
* *Output:*
```
current: home.html
current: home.html
current: home.html
```
