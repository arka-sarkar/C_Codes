### In-Place Sorted Merge of Two Doubly Linked Lists

**Problem Statement:**
In a doubly linked list, every pointer link has an opposite partner: whenever `a->next = b`, it must also hold that `b->prev = a`.

Given two separately constructed doubly linked lists $L_1$ and $L_2$, each sorted in ascending order of integer values, write a function that merges them into a single sorted doubly linked list **in place**.

**Crucial Constraints:**
- Do **not** allocate any new nodes (`malloc` is strictly disallowed inside the merge function).
- Do **not** copy integers between nodes.
- Re-splice all existing nodes together by carefully updating `prev` and `next` pointers.
- The merged list must be valid for both forward (`next`) and backward (`prev`) traversals.

Each node contains:
`typedef struct dnode { int data; struct dnode *prev, *next; } DNode;`

Implement and use the following functions:
1. `DNode *push_back(DNode *head, DNode **tail, int val)`: Appends an element to the end of a doubly linked list and updates `*tail`.
2. `DNode *merge_sorted(DNode *h1, DNode *h2, DNode **out_tail)`: Merges the two sorted lists in place, returns the new head, and sets `*out_tail` to the final node of the merged list.
3. `void print_forward(const DNode *head)`: Prints elements from `head` to `tail` separated by `<->`.
4. `void print_backward(const DNode *tail)`: Prints elements from `tail` to `head` separated by `<->`, verifying all `prev` pointers.
5. `void free_list(DNode *head)`: Frees the single merged list.

**Input Format:**
- An integer $n_1$ followed by $n_1$ sorted integers for the first list.
- An integer $n_2$ followed by $n_2$ sorted integers for the second list.

**Output Format:**
- `Forward:` followed by the merged list printed from head to tail.
- `Backward:` followed by the merged list printed in reverse from tail to head.

**Test Cases:**

* **Test Case 1:**
* *Input:*
```
4
2 5 8 12
3
3 5 10
```
* *Output:*
```
Forward:
2 <-> 3 <-> 5 <-> 5 <-> 8 <-> 10 <-> 12
Backward:
12 <-> 10 <-> 8 <-> 5 <-> 5 <-> 3 <-> 2
```

* **Test Case 2:**
* *Input:*
```
3
1 4 7
0
```
* *Output:*
```
Forward:
1 <-> 4 <-> 7
Backward:
7 <-> 4 <-> 1
```
