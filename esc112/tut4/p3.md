### Priority Task Scheduler with Sorted Insertion and Cancellation

**Problem Statement:**
Operating systems schedule tasks based on priority. Build a priority queue using a singly linked list where tasks are kept sorted in **descending order of priority** (higher priority number = executes earlier).

If two tasks have the identical priority, the earlier task must remain ahead of the later task (First-In, First-Out for ties).

Each task node contains:
`typedef struct task { char name[50]; int priority; int duration; struct task *next; } Task;`

Implement and use the following functions:
1. `int insert_task(const char *name, int priority, int duration)`:
   Inserts the new task in its correct sorted position using one pass with `prev` and `cur` pointers. (Two links: `t->next = cur; prev->next = t;`, or updates `head` if first).
2. `void peek_task(void)`:
   Prints the highest priority task (`head`) without removing it: `peek: <name> (priority <prio>, duration <dur>)` (or `queue is empty`).
3. `void pop_task(void)`:
   Removes and frees the highest priority task (`head`), and prints: `executing: <name> (priority <prio>, duration <dur>)` (or `queue is empty`).
4. `int cancel_task(const char *name)`:
   Searches for a task by name anywhere in the queue (front, middle, or end), unlinks it, and frees it. Returns `1` if found and canceled, or `0` if absent.
5. `void show_tasks(void)`:
   Prints all tasks in order: `name(priority,duration) -> ...` (or `queue is empty`).
6. `void free_all(void)`:
   Frees all remaining tasks before exiting.

**Command Set:**
- `insert <name> <priority> <duration>`
- `peek`
- `pop`
- `cancel <name>`: Prints `canceled <name>` or `not found`.
- `show`
- `end`: Frees memory and stops.

**Test Cases:**

* **Test Case 1:**
