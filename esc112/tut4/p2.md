### Word Frequency Buckets with Threshold Pruning

**Problem Statement:**
A text analyzer maintains word frequencies using an array of 26 linked lists (one bucket per initial English letter `'a'` through `'z'`).

Implement a hash bucket system `Node *table[26]` where words starting with letter $c$ are mapped to bucket index $c - \text{'a'}$.

Implement and use the following functions:
1. `int get_bucket(const char *word)`: Computes `word[0] - 'a'`.
2. `Node *find_word(int b, const char *word)`: Traverses bucket $b$ and returns the node matching `word`, or `NULL` if not found.
3. `int add_word(const char *word)`: If the word already exists in its bucket, increments its frequency `count`. Otherwise, allocates a new node and inserts it at the front of its bucket (`count = 1`). Returns `1` on success, or `0` on memory failure.
4. `int prune(int min_count)`: Walks through all 26 buckets and deletes all nodes whose `count < min_count`. Deletion must link the preceding node (`prev`) to `cur->next` and free `cur`. Returns the total count of deleted nodes.
5. `void show(void)`: Prints each non-empty bucket in the format: `letter: word(count) -> word(count)`.
6. `void free_all(void)`: Frees all remaining nodes in all buckets before termination.

**Command Set:**
- `add <word>`: Adds or increments the word.
- `query <word>`: Prints the frequency of `<word>` (prints `0` if not found).
- `prune <min_count>`: Prunes nodes with count strictly less than `min_count` and prints `pruned: <count>`.
- `show`: Displays all non-empty buckets.
- `end`: Frees all memory and exits.

All words are single words of lowercase letters (`a`–`z`, at most 49 characters). Use safe `scanf("%49s", word)`.
