### Reverse Words in a Sentence (In-Place)

**Problem Statement:**
Write a program that takes a full sentence and reverses the order of the words. You must perform this operation **in-place**. This means you cannot declare a second character array to store the reversed sentence; you must modify the original array directly.

**Constraints:**

* The input is a single line of text ending with a newline.
* Words are separated by exactly one space, with no leading or trailing spaces.
* The maximum length of the sentence is 200 characters.
* Pointers and `string.h` are strictly forbidden.

**Sample Input 1:**

> the cat jumped

**Sample Output 1:**

> jumped cat the

**Sample Input 2:**

> programming in c is fun

**Sample Output 2:**

> fun is c in programming
